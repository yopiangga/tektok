# Tactical Operations Command System (TOCS)
## System Blueprint v1.0

---

# Overview

## Objective

Build a web-based Tactical Operations Command System (TOCS) for monitoring, coordinating, and documenting field operations.

The system is designed for approximately **100 concurrent active personnel** and consists of only two applications:

1. Command Center Dashboard
2. Personnel Web Application

No AI features.
No CCTV integration.
No mobile application (browser only).

---

# Design Principles

## Dashboard

- Information-rich
- Real-time updates
- Easy situational awareness
- Minimal clicks
- Responsive
- Dark mode optimized
- Designed for large monitors

---

## Personnel

- Extremely simple
- Large buttons
- Easy for non-technical users
- Maximum 2-3 clicks for every action
- Mobile-first responsive design

---

# User Roles

## 1. Commander

Permissions

- View all personnel
- View map
- View reports
- Watch live streams
- Create incidents
- Assign missions
- Monitor activities
- Export reports

---

## 2. Operator

Permissions

- Monitor dashboard
- Verify reports
- Create incidents
- Assign missions
- Watch streams

Cannot

- Manage users
- Delete operations

---

## 3. Personnel

Permissions

- Login
- Share GPS
- Submit reports
- Start streaming
- View assigned missions
- Receive notifications
- Chat with operator

Nothing else.
